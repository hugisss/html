Projekt: Web o vesmíru
Tento projekt vznikl jako školní úkol zaměřený na tvorbu jednoduchého vícestránkového webu, praci s verzovacím systémem Git a vyzkoušení práce s umělou inteligencí při psaní kódu.

O čem web je
Zvolil jsem si téma vesmíru, protože mě zajímá astronomie a výzkum kosmu. Web obsahuje základní informace o vesmíru, jednoduchou fotogalerii a podstránku s kontaktním formulářem a přehledem použitých zdrojů.

Struktura projektu
Projekt se skládá z následujících souborů:

index.html - Hlavní stránka s úvodním textem o vesmíru.

galerie.html - Podstránka se dvěma tematickými obrázky.

kontakt.html - Podstránka s kontaktním formulářem, odkazy na zdroje a citací AI.

style.css - Externí stylopis, který definuje tmavý vzhled webu pro všechny stránky.

Obrázky - vesmir-uvod.jpg, planeta.jpg, galaxie.jpg.

Použité technologie
HTML5 pro strukturu stránek

CSS3 pro vzhled a rozvržení

Git a GitHub pro verzování a hosting

Použitá AI a zdroje
Při tvorbě kódu mi pomáhala umělá inteligence Google Gemini.

Hlavní prompt, který jsem použil:
"Jsem začátečník. Chci vytvořit moderní tmavý web o vesmíru. Napiš mi kompletní kód pro hlavní stránku, podstránky a style.css."
